# 用語集

## 1. 目的

本書は、プロジェクト内で使う用語の意味を揃えるための参照文書である。

要件、設計、インターフェース仕様、ファイル形式仕様で同じ言葉を使う場合は、本書の意味に合わせる。個別機能の仕様や内部実装の詳細は、それぞれの仕様書または設計文書に置く。

## 2. 用語

| 用語 | 説明 |
| --- | --- |
| プロジェクト | ひとつの革製品または型紙セット。 |
| プロジェクトファイル | プロジェクトを保存・読み込みするための独自形式ファイル。 |
| Undo | 直前に成功した編集操作を元に戻す操作。 |
| Redo | Undoで戻した編集操作を再適用する操作。 |
| Undo単位 | ユーザーにとって1つの操作として元に戻せる変更単位。 |
| Core セッション | 1つの編集中プロジェクトについて、Core の現在状態と Undo/Redo 履歴を保持する接続単位。 |
| 自動復旧スナップショット | 異常終了時に未保存変更を復旧するため、通常のプロジェクトファイルとは別に端末内へ保存する一時データ。 |
| パーツ | 革を切り出す単位。外形、穴、名称、配置基準点、付随要素を持ち、作成後は位置以外の形状を固定する。 |
| パーツ本体 | パーツの外形や穴を構成する輪郭。 |
| パーツ付随要素 | パーツに紐づく穴、縫い線、寸法表示、折り線、注記などの製作情報。 |
| パーツ間寸法連動 | パーツ化前の複数図形が同じ名前付きパラメータを参照し、作成時の寸法を一致させる限定的な連動。固定後にパーツ形状を更新する機能や、パーツ同士を直接参照する拘束とは区別する。 |
| パーツライブラリ | よく使うパーツを端末内へ登録し、別プロジェクトへ配置するための再利用一覧。 |
| パラメータ | 幅、高さ、ピッチなどの可変値。 |
| 基本図形 | 現行プロダクトで直接作成・編集できる点、線分、円、円弧。 |
| 制御点 | 円の中心や円弧の端点など、図形を操作・拘束するための点。 |
| 複合図形 | 複数の基本図形を接続・拘束・グループ化して構成する輪郭や形状。 |
| 閉じた輪郭 | カット対象やパーツ外形として扱える、端点が連結された線分・円弧などの集合。 |
| 閉領域 | 閉じた輪郭から解釈される面積を持つ領域。パーツ判定や穴判定で利用する。 |
| 外側ループ | パーツ外形を表す閉じた輪郭。 |
| 内側ループ | 外側ループ内にある穴や切り抜き部分を表す閉じた輪郭。 |
| 拘束 | 点・線・寸法・角度などを制御する条件。 |
| 幾何拘束 | 一致、水平、垂直、平行、直交など、図形同士の関係を定義する拘束。 |
| 寸法拘束 | 線分長、距離、角度、直径、半径など、数値で図形を定義する拘束。 |
| 固定拘束 | 図形要素の位置や姿勢を固定する補助拘束。 |
| 対称拘束 | 線分または中心線を対称軸として、点や制御点を上下対称または左右対称に保つ拘束。 |
| 一致点グループ | 一致拘束により同じ位置として扱う点または制御点の集合。 |
| 暗黙拘束 | 図形の成立や評価のために内部的に扱う拘束。 |
| 自動付与拘束 | スナップや方向補正に基づき、作図確定時に追加される拘束。 |
| ユーザー拘束 | ユーザーが明示的に追加する拘束。 |
| 駆動変更 | 寸法値やパラメータ値の変更により、拘束集合を満たす形状を再計算させる変更。 |
| 自由度 | 拘束を追加してもまだ動かせる位置、姿勢、寸法の余地。 |
| 完全拘束 | 対象が基準点または固定対象に対して、位置、姿勢、寸法の自由度を持たない状態。 |
| 拘束不足 | 対象にまだ自由度が残っている状態。 |
| 過拘束 | 既存拘束と重複または過剰な拘束が追加されている状態。 |
| 矛盾拘束 | 既存拘束と両立しない拘束や寸法値を追加・変更しようとした状態。 |
| 冗長拘束 | 既存拘束から既に導けるため、自由度を追加で減らさない拘束。 |
| 中心線 | 対称拘束の対称軸として使う補助線。 |
| 派生要素 | 元の図形または別の派生要素を参照し、参照元の変更に追従して再生成される要素。 |
| フィレット | 接続する図形の角を指定半径の円弧で丸める編集機能。 |
| レイヤースタイル | レイヤーに属する要素へ、個別の共有スタイル指定がない場合に適用する線色、線幅、線種。 |
| 共有スタイル | 名前、線色、線幅、線種をまとめ、複数の図形や派生要素から参照できるプロジェクト単位のスタイル。 |
| 計測表示 | 対象図形から計算した長さ、距離、角度などを表示する、形状を駆動しない注釈。 |
| 寸法拘束表示 | 寸法拘束の値と対象をキャンバス上に示す注釈。表示位置は拘束値とは独立して扱う。 |
| HUD | ヘッドアップディスプレイ。キャンバス上の作業位置近くに一時表示する、入力や状態確認のための小さな補助表示。 |
| 編集表示 | 作図、選択、拘束、注釈などの編集情報を表示するキャンバスモード。 |
| 出力プレビュー | 印刷対象、ページ分割、警告を、実際の PDF または印刷と同じ配置結果で確認する表示モード。 |
| Output Document Model | PDF 出力と直接印刷へ渡す、ページ分割済みの共通出力表現。 |
| カット線 | 革を裁断する線。 |
| 縫い線 | ステッチの基準となる線。 |
| 縫い始め点 | 縫い線上で手縫いを開始する位置を示す点。 |
| 縫い穴 | 菱目打ち、丸穴などで開ける穴。 |
| 丸穴 | 円形の縫い穴。 |
| オフセット線 | 外形線や基準線から一定距離を保って生成される線。 |
| 折り線 | 折り返しや曲げの基準線。 |
| 留め具穴 | ホックなどの留め具を取り付けるための穴。 |
| 注記 | 製作手順や注意点を示すテキスト。 |
| 自由テキスト | 型紙上へ任意の文字列、位置、文字サイズを指定して置く非構造化の注記。 |
