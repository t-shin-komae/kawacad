# UI / UX 仕様書

## 1. 目的

本書は、利用者が観測できる KawaCAD の UI / UX 仕様を定義する。

機能の成立条件、保存・読み込み、出力対象、失敗時に状態を壊さない仕様は `docs/spec/functional-spec.md` を正とする。本書では、画面構成、操作導線、入力中の状態、視覚フィードバック、文言の扱いを記述する。内部処理や未実装案は扱わない。

## 2. 対象範囲

対象は、CAD 基盤、出力プレビュー、レザークラフト固有要素、パーツ管理、アクセシビリティ、ローカライズを含む現行 UI / 操作性である。

菱目などの未実装レザークラフト固有要素、未実装ショートカット、将来候補の導線案は扱わない。

共通の編集画面と出力プレビューは Swift/macOS と Tauri/React で提供する。Swift/macOS は macOS 13 以降を対象とし、PDF 出力と直接印刷へ進める。Tauri/React は Windows・Linux・macOS を対象とし、編集機能と出力プレビューを提供するが、PDF 生成と直接印刷の導線は表示しない。

### 2.1 アプリアイコン

アプリアイコンは、茶寄りのオレンジ色の角丸コースターへ、濃色の革で作った `K` を明色の糸で縫い付けた意匠とする。Swift/macOS 版と Tauri/React 版は、対応するデスクトッププラットフォームで同じ意匠を使用する。原画は[アプリアイコン SVG](../../artifacts/icon-candidates/candidate-a-saddle-stitch.svg)を正とする。

### 2.2 About画面

- About画面は、メニューバーの `KawaCAD` > `KawaCADについて` から開く。
- About画面には、アプリアイコン、アプリ名 `KawaCAD`、バージョン、コピーライト `© 2026 t-shin-komae` を表示する。
- 開発中のバージョンは `Version 0.1.0-dev`、正式リリース版は `Version 0.1.0` の形式で表示する。
- Swift/macOS 版は macOS 標準の About パネルを使用する。Tauri/React 版は各デスクトップ環境のネイティブ About 項目を使用する。
- ビルド番号は表示しない。

## 3. ワークスペース構成

アプリケーションは、単一ドキュメントを編集するワークスペースとして動作する。

| 領域                  | 主な役割                                                           |
| --------------------- | ------------------------------------------------------------------ |
| キャンバス            | 図形の作成、選択、ドラッグ、拘束マーク、計測表示、プレビューの確認 |
| 上部ヘッダ/ツールバー | プロジェクト名、作図レイヤー、ズーム、表示補助、表示モードの操作   |
| ツール領域            | 作図、派生要素、幾何拘束、寸法拘束、計測表示の起点                 |
| インスペクタ          | 選択中要素の値確認と編集、レイヤー、パラメータ、パーツの管理       |
| 下部サマリー          | 選択、拘束、パラメータ、件数などの補助情報                         |
| ステータスバー        | 表示数、選択状態、座標、直近操作メッセージ                         |

- 上部には、プロジェクト名、`.kawa` 形式、単位、用紙、レイヤー選択、拘束状態、ズーム、表示切り替えへ到達できる細いヘッダ領域を表示する。
- プロジェクト名欄の有効な編集中値は、保存、別名保存、新規作成、開く操作の前に確定する。無効な値は欄に理由を表示し、操作を開始しない。
- キャンバス下部のステータスバーには、レイヤー数、表示数、選択状態、座標、直近の操作メッセージを表示する。
- メインウィンドウは少なくとも 1024x700 pt で主要操作へ到達できる。
- 表示中の画面幅よりウィンドウが広い場合は、ウィンドウ幅を画面内に収め、インスペクタを画面外へ欠けさせない。
- レイアウトは、左ツール領域を表示した後に残るワークスペース幅で `compact`、`regular`、`wide` を切り替える。`wide` はキャンバスとインスペクタを同時にドッキングできる場合に使用する。上部ツールバーは利用可能幅に応じて表示密度を切り替え、インスペクタを画面外へ押し出さない。
- `wide` ではツール領域とインスペクタを左右へドッキング表示し、幅をドラッグで変更できる。
- `regular` ではツール領域を左へドッキング表示し、インスペクタは右側の重ね表示で開く。
- `wide` と `regular` の左ツール領域はウィンドウ上端から連続して表示し、上部ヘッダ/ツールバーの下に空白帯を作らない。
- ドッキングしたパネルのリサイズハンドルは、ドラッグ、フォーカス後の左右矢印キー、VoiceOver の調整操作で幅を増減できる。
- `compact` ではツール領域とインスペクタをキャンバス上の drawer として開き、同時には1つだけ表示する。
- インスペクタは、タブ列と値列を表示できる幅を常に確保し、ウィンドウ幅の変化によって右端を欠けさせない。
- ツール領域は、作図、派生要素、幾何拘束、寸法拘束、計測表示の区画に分け、折り畳み状態を保持しながら表示する。
- 下部サマリーは初期状態では非表示とし、必要時だけ開く。
- ツール領域、インスペクタ、レイヤー、パラメータ、下部サマリーは表示/非表示を切り替えられる。
- 最後のドキュメントウィンドウを閉じると、アプリケーションは終了する。

## 4. メニューと主要コマンド

### 4.1 ファイル系

| メニュー項目     | ショートカット    | 動作                             |
| ---------------- | ----------------- | -------------------------------- |
| 新規プロジェクト | `Command-N`       | 新しい空ドキュメントを作成する   |
| 開く...          | `Command-O`       | `.kawa` ファイルを選択して開く |
| 保存             | `Command-S`       | 現在の保存先へ保存する           |
| 別名で保存...    | `Command-Shift-S` | 保存先を選んで保存する           |

- 保存と別名保存は、ドキュメントが利用可能なときだけ実行できる。
- 開く操作では `.kawa` JSON ファイルを選択する。
- 保存先選択では KawaCAD プロジェクト保存用のダイアログを表示する。

### 4.2 編集系

| メニュー項目             | ショートカット    | 動作                                                                                     |
| ------------------------ | ----------------- | ---------------------------------------------------------------------------------------- |
| 元に戻す                 | `Command-Z`       | 直前の編集を取り消す                                                                     |
| やり直す                 | `Command-Shift-Z` | 取り消した編集をやり直す                                                                 |
| カット                   | `Command-X`       | テキスト入力中は標準テキスト編集を優先する                                               |
| コピー                   | `Command-C`       | テキスト入力中は標準テキスト編集、キャンバスでは選択図形コピー                           |
| ペースト                 | `Command-V`       | テキスト入力中は標準テキスト編集、キャンバスではカーソル文脈に応じてコピー図形をペースト |
| 複製                     | `Command-D`       | 選択図形を複製する                                                                       |
| 削除                     | `Delete`          | 選択中の図形、拘束、計測表示、自由テキストを削除する                                     |
| すべてを選択             | `Command-A`       | テキスト入力中は標準テキスト編集、キャンバスでは全エンティティ選択                       |
| 選択解除またはキャンセル | `Esc`             | 進行中操作を1段階キャンセルする                                                          |

- テキスト入力中は、標準テキスト編集をキャンバス操作より優先する。
- Undo/Redo ができない状態では該当メニューは無効になる。
- 複製、削除は、対象がない場合は無効またはステータス表示で案内する。

### 4.3 作図・拘束・表示・レイヤー・出力

| メニュー | 主な項目                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 作図     | 選択、点、線分、円、円弧、テキスト、縫い始め点、中心線、水平中心線、垂直中心線                           |
| 拘束     | 一致、水平、垂直、平行、直交、接線、同長、角度、対称、固定、距離、水平距離、垂直距離、線分長、直径、半径 |
| 表示     | 編集表示モード、出力プレビューモード、パネル表示、レイアウトを初期状態に戻す、再読込                     |
| レイヤー | レイヤー追加                                                                                             |
| 出力     | PDF出力...、直接印刷...                                                                                  |

- 作図メニューの選択、点、線分、円、中心線には `Command-1` から `Command-5` のショートカットがある。
- 水平拘束は `Command-Shift-H`、垂直拘束は `Command-Shift-V` で選択できる。
- 編集表示モードは `Command-Option-1`、出力プレビューモードは `Command-Option-2` で選択できる。
- 再読込は `Command-R`、レイヤー追加は `Command-Shift-L` で実行できる。
- PDF出力と直接印刷は、ドキュメントが利用可能なときだけ実行できる。

## 5. ツールパレット

### 5.1 ツール分類

| 区画                | ツール                                                                   |
| ------------------- | ------------------------------------------------------------------------ |
| 作図                | 選択、線分、円、円弧、丸穴、テキスト、縫い始め点                         |
| 基本寸法            | オフセット、フィレット、距離、水平距離、垂直距離、線分長、直径、半径     |
| 派生                | 点、中心線、水平中心線、垂直中心線                                       |
| 幾何拘束            | 一致、水平、垂直、平行、直交、接線、同長、角度、対称、直線上、固定       |
| 詳細寸法 / 計測表示 | 線線距離、距離表示、線分長表示、角度表示、半径表示、直径表示、円弧角表示 |

- 各ツールはアイコンと日本語ラベルで表示する。
- ツールパレット上部には「型紙線種」セクションを表示し、プロジェクト内の共有スタイルを選択できる。
- 「型紙線種」セクションには、選択中の共有スタイルを選択図形へ適用するボタンを表示する。
- 初期状態では基本表示とし、作図と基本寸法を展開表示する。
- 詳細ツールを表示すると、派生、幾何拘束、詳細寸法 / 計測表示を追加表示する。
- 区画ごとの折り畳み状態は利用者設定として保持する。
- 選択中のツールが折り畳まれた区画に属する場合は、その区画を一時的に表示して active tool を見失わない。
- 選択中のツールは強調表示する。
- ツール選択時は、ステータスバーに次に行う操作を短く表示する。
- 現行仕様で有効なツールだけを実行可能にする。

### 5.2 アイドル時の案内

- 選択ツールでは「エンティティを選択します」という趣旨の案内を表示する。
- 作図ツールでは、始点、中心、半径点、終点など、次にクリックすべき対象を表示する。
- テキストツールでは、テキストを配置する位置をクリックするよう案内する。
- 拘束ツールでは、必要な対象種別と選択数を表示する。
- オフセットツールでは、オフセット元を選ぶよう案内する。
- フィレットツールでは、接続する線分または中心線を2本以上、あるいは線分または中心線と円弧を1本ずつ選ぶよう案内する。
- 丸穴ツールでは、丸穴の中心をクリックするよう案内する。
- 縫い始め点ツールでは、縫い始め点を置く線分、中心線、円弧をクリックするよう案内する。
- 計測表示ツールでは、表示する寸法や角度に必要な対象を表示する。

## 6. キャンバス

### 6.1 座標と表示

- キャンバスは、用紙中心を原点、右方向を X 正方向、上方向を Y 正方向とする作図座標を扱う。
- ステータスバーには、ポインタ位置の座標を `X ... / Y ... mm` の形式で表示する。
- 座標が取得できない状態では、座標なしの表示にする。
- A4基準表示を有効にすると、作図位置確認用の原点固定A4 5x5グリッドを表示する。
- グリッド表示を有効にすると、作図補助用の格子をA4 5x5範囲に表示する。

### 6.2 パン・ズーム

- トラックパッドの2本指パンは表示移動として扱う。
- ピンチはズームとして扱う。
- ツールバーからズームイン、ズームアウト、全体表示を実行できる。
- ツールバーには現在のズーム倍率をパーセントで表示する。
- 表示倍率100%では、PDF / PostScript の文書座標に合わせ、モデル上の1mmを `72 / 25.4` 論理画面単位で表示する。表示倍率は実寸出力倍率とは独立し、ディスプレイの高解像度倍率によって変えない。
- 全体表示は、ズーム倍率とキャンバス表示位置を初期状態へ戻す。

### 6.3 選択表示

- 選択中の図形は未選択状態と区別できる。
- 選択中の自由テキストは、未選択状態と区別できる。
- 複数選択中は、選択数をステータスバーや下部サマリーに表示する。
- 制御点、拘束マーク、計測表示は、選択またはホバーで強調される。
- ホバー強調は、その時点のツールでクリック可能な対象に限定する。
- 無効対象は、拘束追加や計測表示追加のホバー強調対象にしない。
- 選択ツールで空白から左→右へドラッグした範囲選択は、矩形へ全体が収まる図形だけを選択する。青系の実線矩形、候補ハイライト、`完全に含まれる図形を選択: N件` を表示する。
- 右→左へドラッグした範囲選択は、矩形内の図形または矩形境界と交差する図形を選択する。緑系の破線矩形、候補ハイライト、`交差する図形を含めて選択: N件` を表示する。
- ドラッグ中に方向を反転すると、選択方式、矩形表示、候補ハイライト、候補件数を直ちに切り替える。VoiceOver には方式と候補件数を公開する。
- 範囲選択では、候補と確定結果の論理選択件数を一致させ、ドキュメント、変更状態、Undo/Redo 履歴を変更しない。

## 7. 作図操作

### 7.1 点・線分・中心線

- 点ツールでは、キャンバス上のクリック位置に点を作成する。
- 線分ツールでは、始点をクリックした後、終点をクリックして線分を作成する。
- 中心線ツールでは、始点と終点をクリックして中心線を作成する。
- 水平中心線、垂直中心線では、指定方向に補正された中心線を作成する。
- 線分または中心線の作図中は、次に終点をクリックする状態であることを表示する。
- ゼロ長になる配置は拒否し、ステータス表示で案内する。

### 7.2 円

- 円ツールでは、中心をクリックした後、半径を決める点をクリックして円を作成する。
- 中心と半径点が同じになる配置は拒否する。

### 7.3 円弧

- 円弧ツールでは、中心、開始点、終点の3段階で円弧を作成する。
- 作図中は、次に開始点または終点をクリックする状態であることを表示する。
- 作図中に掃引角をキャンバス上へ表示する。
- 作図中は、開始点からの回転方向と回転量を追跡し、180 度を超える円弧も短い側へ反転させない。
- `Shift` 押下中は、円弧の掃引角を補正できる。補正後の掃引角が 180 度を超える場合も、その値を維持する。
- 開始点が中心と同じ場合、または終点が開始点と同じ角度になる場合は拒否し、ステータス表示で案内する。
- 円弧作成直後は選択状態を維持し、開始角と掃引角を続けて編集できる。
- 円弧作成後に別の図形へ選択が切り替わる場合、直前のインスペクタ入力を新しい選択へ適用しない。作成結果と入力エラーは対象を混同せずに表示する。

### 7.4 スナップ

- 点スナップは、端点、中点、中心などの既存点に吸着する。
- グリッドスナップは、作図位置をグリッドに吸着する。
- 線分作図では、既存点へのスナップ、水平/垂直補正、Shift補正を表示に反映する。
- 既存点へスナップした線分端点には、自動一致拘束を追加する。
- 水平/垂直補正で確定した線分には、自動水平拘束または自動垂直拘束を追加する。
- `Control` キー押下中は、作図中とドラッグ中のスナップを一時的に無効化し、`SNAP OFF` を表示する。

### 7.5 テキスト

- テキストツールでは、キャンバス上のクリック位置に自由テキストを配置する。
- 自由テキスト配置直後は、その自由テキストを選択状態にし、配置位置で直接文字入力できる。
- 配置済み自由テキストは、ダブルクリックまたはコンテキストメニューの「テキストを編集」から、キャンバス上で直接編集できる。
- 配置済み自由テキストは、選択ツールでドラッグして移動できる。
- 選択中の自由テキストは、インスペクタで表示文字列、X/Y 位置、文字サイズを編集できる。
- 選択中の自由テキストは、インスペクタ、コンテキストメニュー、または削除操作で削除できる。

### 7.6 丸穴

- 丸穴ツールでは、キャンバス上のクリック位置を中心として丸穴を配置する。
- 左ツールパレットには「丸穴」セクションを表示し、穴種別と直径を選択できる。
- 穴種別は、キーリング穴、カシメ穴、ジャンパーホック穴、装飾穴から選択する。
- 直径は mm 単位で入力する。
- 正の有限値ではない直径では、丸穴を配置せず、ステータスバーに入力修正を促す。
- 丸穴作成直後は選択状態を維持し、穴種別と直径を続けて編集できる。

### 7.7 縫い始め点

- 縫い始め点ツールでは、キャンバス上の線分、中心線、円弧、またはそれらとして表示される派生要素をクリックして縫い始め点を配置する。
- 配置可否は図形種別で判定し、共有スタイルの有無や種類には依存しない。点、円、およびそれらとして表示される派生要素は配置対象にしない。
- 縫い始め点は、キャンバス上で小さな点 marker として表示する。
- 縫い始め点作成直後は、その縫い始め点を選択状態にする。
- 選択中の縫い始め点は、未選択状態と区別できる。
- 配置対象ではない場所をクリックした場合は、線分、中心線、円弧上へ配置するようステータスバーで案内し、縫い始め点を作成しない。

## 8. 選択と編集

### 8.1 共有スタイル

- インスペクタには、プロジェクト内の共有スタイル一覧を表示する。
- 新規プロジェクトでは、レザークラフトで使う代表的な共有スタイルが最初から一覧に表示される。
- 共有スタイル一覧では、共有スタイルを追加できる。
- 各共有スタイルでは、名前、線種、線色、線幅を編集できる。
- 各共有スタイルは削除できる。
- 図形または派生要素を選択すると、選択セクションに共有スタイルの選択欄を表示する。
- 共有スタイルの選択欄では、未設定または既存共有スタイルを選択できる。
- 複数の図形または派生要素を選択している場合も、共有スタイルをまとめて適用できる。
- 左ツールパレットの「型紙線種」で共有スタイルを選択すると、それ以降に作図する線分、円弧、中心線、水平中心線、垂直中心線、および作成するオフセット線へ適用される。
- 左ツールパレットの「選択へ適用」を実行すると、現在の型紙線種を選択中の図形または派生要素へまとめて適用する。
- 派生要素の解決済み図形を選択した場合、共有スタイルの選択欄は派生要素本体への適用として動作する。
- 共有スタイルを編集すると、その共有スタイルを使う図形と派生要素のキャンバス表示が更新される。

### 8.2 丸穴編集

- 丸穴を選択すると、インスペクタの選択セクションに穴種別と直径の編集欄を表示する。
- 穴種別の変更は、選択中の丸穴へ反映する。
- 直径の変更は、選択中の丸穴の円形状へ反映する。
- 正の有限値ではない直径では、変更を反映せず、ステータスバーに入力修正を促す。
- 丸穴は、選択ツールでドラッグして移動できる。

### 8.3 選択解除とキャンセル

- 空白クリックは選択解除として扱う。
- `Esc` は、入力中、ドラッグ中プレビュー、作図ドラフト、拘束対象選択、選択集合の順で1段ずつキャンセルする。
- キャンセル後は、ステータスバーにキャンセルまたは選択解除の結果を表示する。
- キャンバスにフォーカスがあるとき、`V` は選択ツールへ切り替える。
- 選択中の縫い始め点は、削除操作で削除できる。
- キャンバスにフォーカスがあり、進行中操作や選択解除対象がない状態で選択ツール以外を使用している場合、`Esc` は選択ツールへ切り替える。

### 8.4 コンテキストメニュー

- 右クリックでは、空白領域、エンティティ、拘束マーク、計測表示に応じたコンテキストメニューを表示する。
- 計測表示では、「拘束へ変換」「計測表示を削除」を表示する。
- 拘束マークでは、「拘束を削除」を表示する。
- エンティティでは、「選択エンティティをコピー」「選択エンティティを複製」「選択エンティティを削除」を表示する。
- 空白領域では、「ペースト」「すべてを選択」を表示する。編集メニュー、`Command-V`、空白領域のペーストは同じ操作として扱う。
- 空白領域からのペーストは、右クリック位置を基準にする。カーソル位置を使えない場合やコピー元と重なる場合は、コピー元付近へ5 mmずらして配置する。

### 8.5 コピー・ペースト・複製・削除

- 選択対象をコピーすると、ステータスバーにコピー結果を表示する。派生要素や注釈などの成立に必要な依存対象は Core が含める。
- コピー対象がない場合、コピーする対象を選択するよう表示する。
- ペースト対象がない場合、ペーストする対象がないことを表示する。
- ペースト直後は、貼り付けた選択範囲の近くに「ペーストオプション」を表示する。利用者は「カーソル位置」と「コピー元の近く（+5 mm）」を切り替えられ、次の編集、選択変更、コピー内容の変更、または `Esc` で閉じる。
- ステータスバーは、ペーストした論理要素数と、カーソル座標またはコピー元からのずらし量を表示する。
- 複製後は、新しく作成された複製を選択する。
- 複数選択したエンティティを `Delete` で削除した場合、1回の操作として削除する。
- 削除対象に含まれる派生フィレットの参照切れ警告は、対象全体を削除した操作では表示しない。

### 8.6 ドラッグとプレビュー

- 拘束で接続された図形をドラッグすると、関連図形も拘束を満たす範囲で連動プレビューする。
- ドラッグ中のプレビューは、マウスボタンを離すまで正式な変更として確定しない。
- 通常移動と `Option` + ドラッグ複製は、キャンバス上のバッジで区別する。
- 複数選択をドラッグしている場合、バッジに対象件数を表示する。
- ドラッグが確定すると、移動または複製完了をステータスバーに表示する。
- 単一の線分または中心線をドラッグして全体移動が解けない場合、片端だけの伸縮として解ける候補があれば、その伸縮プレビューと確定を行う。
- 線分または中心線の端点をドラッグしてマウス位置そのものでは拘束を解けない場合、元の線分方向へ射影した伸縮として解ける候補があれば、その伸縮プレビューと確定を行う。
- 解けない移動を行った場合はエラーを表示し、ドラッグ前の状態へ戻す。

## 9. 拘束と寸法入力

### 9.1 対象選択

- 拘束追加ツールでは、選択済み件数と次に選ぶべき対象種別を表示する。
- 拘束追加ツールでは、クリック可能な対象をホバー時にキャンバス上で強調し、無効対象は強調しない。
- 拘束追加ツールでは、点を主対象にするツールは制御点を優先し、線分を主対象にするツールは線分を優先する。
- 円や円弧を主対象にする寸法拘束では、エンティティ本体を対象として扱う。
- 通常の拘束追加では派生要素を対象にしない。オフセット、フィレット、フィレット半径編集では派生要素編集として扱える。
- 対象が不足している場合、必要な対象数、現在の選択数、次に選ぶべき対象種別を表示する。
- 拘束対象を選択中は、作業位置近くに次に選ぶべき対象種別を短い補助表示として出す。

### 9.2 寸法入力 HUD

- 寸法拘束は、対象選択後にキャンバスを暗転させず、作業位置近くの入力 HUD で確定する。
- 入力 HUD では、固定値入力と名前付きパラメータ参照を切り替えられる。
- 参照可能なパラメータがない場合は、固定値入力を使う。
- 固定値では数値と単位を表示する。
- パラメータ参照では、パラメータ名、値、単位を選択肢として表示する。
- `Enter` または既定アクションで確定し、キャンセルで入力を破棄する。
- 固定値が空、ゼロ、負数、非数、無限大の場合は、正しい値を入力するよう表示する。

### 9.3 寸法拘束表示

- 寸法拘束は、寸法線、補助線、両端矢印または角度弧、寸法値ラベルとして表示する。
- 寸法拘束表示は計測表示と近い構成で表示し、計測表示とは線色で区別する。
- 選択ツールで寸法拘束のラベルをドラッグすると、ラベル位置だけを移動できる。
- 選択ツールで寸法拘束の寸法線または角度弧をドラッグすると、表示全体の位置を移動できる。
- 寸法拘束表示の位置移動中は、対象図形や拘束値を変更しない。

### 9.4 幾何拘束

- 一致、水平、垂直、平行、直交、接線、同長、固定、対称、直線上は、対象選択後に必要条件を満たせば拘束を追加する。
- 点/制御点の直線上拘束では、点 target と線 target を順に選択し、値入力なしで拘束を追加する。
- 直線上拘束の表示名は、有限線分上の保証に見えない「直線上」寄りの文言を使う。
- 接線拘束では、線分または中心線の始点/終点と、円弧の開始点/終了点を選択する。
- 接線拘束では、接続済みの線分系端点と円弧端点を選ぶよう案内し、値入力なしで拘束を追加する。
- 接線拘束を追加すると、線分側から接続点へ進んでそのまま円弧へ入る向きで、円弧が滑らかにつながる位置へ更新される。
- 接線拘束の対象が接続していない場合は、先に一致拘束などで端点を接続する必要があることを示す文言を表示する。
- 円弧を選択している場合、メニューまたはコンテキストメニューから試作の「両端を接線化」を実行できる。円弧の開始点・終了点がそれぞれ線分または中心線に接続済みの場合、両端が滑らかに接続するよう円弧を更新し、接線拘束を追加する。
- 試作の「両端を接線化」は、対象円弧が未選択、接続線分が2本揃っていない、または解けない場合はステータスバーに失敗理由を表示し、作図状態を変更しない。
- 対称拘束では、対称にする点を2件選んだ後、対称軸にする中心線または線分を選ぶよう案内する。

### 9.5 距離・長さ・直径・半径

- 距離拘束では、2点、または点/制御点と線分/中心線を対象にできる。
- 距離拘束では、線分端点、中心線端点、円中心、円弧中心、円弧開始点、円弧終了点を制御点として選択できる。
- 水平距離拘束と垂直距離拘束では、点/制御点を2件選択した後に距離入力 HUD を表示する。
- 水平距離拘束と垂直距離拘束は、キャンバス上に対象2点からの補助線、軸方向の寸法線、軸名付きの距離ラベルを表示する。
- 線線距離拘束では、線分または中心線を2本選択した後に距離入力 HUD を表示する。
- 線分長拘束では、線分または中心線を選択した後に長さ入力 HUD を表示する。
- 直径拘束では円を選択した後に直径入力 HUD を表示する。
- 半径拘束では円または円弧を選択した後に半径入力 HUD を表示する。

### 9.6 角度

- 2線分の角度拘束では、1本目と端点を共有する線分を2本目の候補として扱う。
- 入力 HUD の初期値は、共有端点から見た1本目方向から2本目方向への符号付き角度とする。
- 2線分の角度拘束では、共有端点を中心に、1本目方向から2本目方向へ向かう角度弧と矢印をキャンバスに表示する。
- 角度ラベルは `45°`、`-45°` のように符号付きで表示し、正負の判別を色だけに依存しない。
- 角度拘束を選択またはホバーすると、角度弧、基準線、角度ラベルを強調する。
- 円弧の角度拘束では、掃引角の符号付き角度ラベルをキャンバスに表示する。
- 端点を共有しない2線分へ角度拘束を追加しようとした場合は、端点を共有する2本の線分が必要であることを示す文言を表示する。

### 9.7 拘束マーク

- 拘束を追加すると、対象図形または制御点の近くに拘束マークを表示する。
- 拘束マークは、通常時は枠なしの省スペースな記号として表示する。
- 一致、水平、垂直、平行、直交、接線、固定、対称、直線上、距離、点-線分距離、線分間距離、線分長、角度、直径、半径、同長拘束を識別できる。
- 拘束マークを選択またはホバーすると、対応する拘束種類名を補助表示する。
- 複数の拘束マークが近接する場合は、重なりを避けて並べる。
- 拘束マークを選択すると、対応する表示を強調し、インスペクタに選択中拘束の属性を表示する。

### 9.8 失敗時の表示

- 拘束失敗時は、エラーコードと補助情報に基づく利用者向け文言を表示する。
- 対象不足では、必要な対象数、現在の選択数、次に選ぶべき対象種別を表示する。
- 不正対象では、その拘束で期待される対象種別を表示する。
- 重複拘束では、同じ拘束が既に追加されていることを表示する。
- 競合拘束では、既存拘束と矛盾することを表示する。
- 参照切れでは、対象が削除されていないか確認するよう表示する。
- 派生要素に拘束を追加しようとした場合は、拘束対象外であることを示す文言を表示する。

## 10. 計測表示

### 10.1 追加

- 計測表示ツールは拘束ツールとは別区画に表示する。
- 計測表示ツールでは、対象選択中に有効な対象をホバー強調し、選択済み対象をキャンバス上で強調する。
- 距離表示では2点を選択する。
- 線分長表示では線分系対象を選択する。
- 角度表示では端点を共有する線分2本を選択する。
- 半径表示では円または円弧を選択する。
- 直径表示では円または円弧を選択する。
- 円弧角表示では円弧を選択する。
- 計測表示では、フィレット解決済み線分を選んだ場合、保存可能な元線分へ対応付けられる場合だけ受け入れる。

### 10.2 表示と編集

- 計測表示は拘束マークとしては表示せず、両端矢印付きの寸法線、角度弧、ラベルとして表示する。
- 計測表示のラベルには、対象図形から再計算した現在値を表示する。
- 選択ツールで計測表示のラベルをドラッグするとラベル位置を移動できる。
- 選択ツールで計測表示の寸法線をドラッグすると、寸法線または角度弧全体の位置を移動できる。
- 計測表示を選択中に `Delete` を押すと削除する。
- 計測表示の右クリックメニューから「拘束へ変換」を実行できる。
- 計測表示を拘束へ変換すると、現在の実測値を初期値にした寸法拘束または角度拘束を追加し、元の計測表示を削除する。
- 変換失敗時は、計測表示を残し、エラーを表示する。

## 11. 派生要素

### 11.1 オフセット

オフセット線は、次の流れで作成する。

1. 一部の連続区間だけに適用する場合は、選択ツールで対象要素を2つ以上選択する。
2. ツールパレットからオフセットツールを選択する。
3. キャンバスでオフセット元をクリックする。
4. 作業位置近くに表示される距離入力 HUD で、距離と対象範囲を確認する。
5. 固定値または名前付きパラメータ参照で距離を確定する。

オフセット元の選び方は次のとおり。

| 操作時の状態                                                           | オフセット元と初期方向                                                   |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 線分、中心線、円弧、既存オフセット線をクリック                         | クリックした要素を元にし、クリックした側を初期方向にする                 |
| 円をクリック                                                           | 円を元にし、クリック位置が円の内側なら内向き、外側なら外向きにする       |
| 複数の連続する線分、中心線、円弧を選択してから、そのうち1つをクリック  | 選択した区間だけを元にし、クリックした側を初期方向にする                 |
| フィレットの元線分を複数選択してから、フィレット適用後の形状をクリック | 選択線分に対応するトリム済み線分と、その間のフィレット円弧だけを元にする |
| 閉じた輪郭に含まれる線分、中心線、円弧をクリック                       | 「閉じた輪郭」と「単独要素」を選べるようにし、既定では輪郭全体を元にする |
| フィレット適用後の閉じた輪郭をクリック                                 | 「閉じた輪郭」を既定にし、フィレット適用後の輪郭全体を元にする           |

- オフセット元にできない対象をクリックした場合は、対象外であることを示す文言を表示する。
- 2つ以上の要素が選択されている場合は、その選択範囲を閉じた輪郭の自動検出より優先し、隣接する未選択要素をオフセット元に追加しない。
- フィレットの元線分を複数選択している場合も、その選択を維持し、クリックしたフィレット全体へ自動拡張しない。
- 選択した複数要素が一続きになっていない場合は、作成を受け付けず、エラーを表示する。
- 距離入力 HUD では、固定値入力と名前付きパラメータ参照を切り替えられる。
- 閉じた輪郭を選んだ場合、クリック位置が輪郭の内側なら内向き、外側なら外向きを初期方向にする。
- 入力完了後、作成されたオフセット線は通常の選択対象としてキャンバスに表示される。
- 作成済みオフセット線を選択すると、インスペクタで距離、固定値とパラメータ参照の切り替え、方向、レイヤーを変更できる。
- インスペクタではオフセット方向を反転できる。
- 元図形変更などでオフセット線が維持できず削除された場合は、警告を表示する。

### 11.2 フィレット

- ツールパレットからフィレットツールを選択できる。
- フィレット元として、接続する線分または中心線を2本以上、あるいは線分または中心線と円弧を1本ずつクリックできる。
- 線分または中心線を2本以上、あるいは線分または中心線と円弧を選択済みの場合、フィレットツールを選ぶだけで選択済みセットを事前検証し、再クリックなしで同じフィレット作成ドラフトと半径入力 HUD を開始する。
- フィレットツール中は、1本目から確定またはキャンセルまで同じ作成ドラフトとして参照線を保持する。2本目以降では、作業位置近くの半径入力 HUD に参照線数、対象角数、開いたパス／閉輪郭を表示する。
- 半径を入力した後も、追加の接続線分または中心線をクリックすると、半径とHUDを維持したままフィレット元を拡張する。円弧を含むドラフトは2本の時点で確定対象とし、追加の要素は受け付けない。重複または無効な対象は、既存ドラフトを変更せず理由を表示する。
- フィレット半径入力では、固定値入力と名前付きパラメータ参照を切り替えられる。
- 3本以上の接続線分または中心線を選択した場合、開いた連続パスでは内部頂点、閉じた輪郭では全頂点をまとめてフィレットする。
- 既存フィレットの解決済み線分と隣接する元線分をフィレット元として選択した場合、既存フィレットを拡張する半径入力として扱う。
- 既存フィレットの拡張操作では、追加後に参照元列が閉じた輪郭になっても、ユーザーが選択していない角を自動でフィレットしない。
- フィレット適用後もキャンバス上では元線分または元中心線を表示し、フィレット適用後の最終形状より薄い線として表示する。
- 作成済みフィレットを選択すると、インスペクタで半径、パラメータ参照、レイヤーを変更できる。
- フィレットの円弧を半径ツールまたは半径ハンドルで操作した場合も、通常円弧ではなくフィレット半径の編集として扱う。
- フィレット元にできない対象をクリックした場合は、対象外であることを示す文言を表示する。
- 接続していない線分、中心線、または円弧をフィレット元として混ぜた場合、または円弧を含む3本以上の組を指定した場合は、半径入力前に対象不正として案内する。
- `Enter` は有効な半径で現在のフィレット作成ドラフトを確定する。`Esc` は最後に追加した参照線を1本ずつ戻し、1本の状態でさらに押すとドラフトをキャンセルする。
- フィレット作成中は、VoiceOver から参照線数、対象角数、開いたパス／閉輪郭、次に線を追加できるか半径を確定できるかを判別できる。

## 12. インスペクタ

### 12.1 ドキュメント概要と選択情報

- インスペクタには、表示モード、作図レイヤー、表示エンティティ数、拘束数、パラメータ数などのドキュメント概要を表示する。
- `compact` では、選択変更後にインスペクタ表示設定が有効なときだけインスペクタ drawer を自動で開く。
- 単一エンティティ選択時は、種別、レイヤー、編集可能な寸法値を表示する。
- 派生要素選択時は、派生要素の種類、参照元数、距離または半径、パラメータ参照、方向操作を表示する。
- 複数エンティティ選択時は、種別の要約、レイヤーの要約、一括操作を表示する。
- 複数選択時は、単一要素向けの属性編集が1つだけ選択したときに表示されることを案内する。
- Core 接続状態、内部ID、残自由度、制御点一覧などの開発者向け情報は、通常のインスペクタには表示しない。

### 12.2 図形値の編集

- 線分では、終点や線分長に関する編集欄を表示できる。
- 円では、半径に関する編集欄を表示できる。
- 円弧では、半径、開始角、掃引角に関する編集欄を表示できる。
- 確定ボタンを持たない入力欄は、`Enter` またはフォーカス喪失で確定する。
- 入力値の確定に失敗した場合は、表示元の値へ戻す。

### 12.3 選択中拘束

- 拘束マークを選択した場合、インスペクタの選択領域に拘束種別を表示し、対象図形または対象点をキャンバス上で強調表示する。
- 寸法拘束では、選択中拘束の値またはパラメータ参照を編集できる。
- 選択中拘束はインスペクタから削除できる。
- 拘束状態や拘束 target の内部表現は通常のインスペクタには表示しない。
- 拘束の全件一覧は通常のインスペクタには表示しない。

### 12.4 パラメータ

- パラメータは一覧または編集領域から追加、編集、削除できる。
- パラメータ名、現在値、単位を一覧で確認できる。
- パラメータがない場合は、名前付きパラメータがまだないことを表示する。
- パラメータの使用状況は、未使用または使用件数として表示する。
- パラメータ名または値が不正な場合は、確認を促すステータスを表示する。

### 12.5 レイヤー

- レイヤーは一覧から追加、名前変更、削除、表示切り替え、印刷対象切り替えを行える。
- レイヤー行では、固定的なレイヤー種別名を常時表示せず、レイヤー名、表示、印刷対象、削除、線スタイルの操作を優先して表示する。
- レイヤー行では、現在の線種、線色、線幅をメニューを開かなくても確認できるよう、文字とプレビューで常時表示する。
- レイヤーごとの線色、線幅、線種をドロップダウンリストから編集できる。
- 線色は代表色プリセットから選択でき、カスタム色では `#RRGGBB` 形式を入力できる。
- 線幅は代表値プリセットから選択でき、カスタム線幅では正のミリメートル値を入力できる。
- レイヤーごとの線色、線幅、線種の変更はキャンバス表示へ即座に反映される。
- 非表示レイヤーに属する要素はキャンバスに表示しない。
- 補助線レイヤーを印刷対象にしようとした場合は、印刷対象にできないことを表示する。
- 線幅が正でない場合は、線幅は0より大きい値が必要であることを表示する。
- 線色入力が不正な場合は、`#RRGGBB` 形式を求める表示を出す。
- 図形が紐づくレイヤー削除では確認ダイアログを表示する。
- 最後のレイヤーを削除しようとした場合は、削除できないことを表示する。

### 12.6 パーツ

- インスペクタのパーツタブに、プロジェクト内のパーツを一覧表示する。
- パーツ一覧では名称と、外形、穴、所属図形の件数を確認できる。
- パーツ一覧では必要数量も確認でき、選択したパーツの表示、印刷対象、1〜999の必要数量を切り替えられる。
- キャンバスで閉じた外形を構成する図形を複数選択し、「選択からパーツを作成」を実行できる。
- 選択がない、外形が閉じていない、別のパーツに所属済みなど作成できない場合は、ステータス表示で選択内容の確認を促す。
- パーツを選択すると、名称と位置の X / Y 座標を編集できる。座標を確定すると、パーツ全体が現在位置との差分だけ移動する。空の名称、重複する名称、不正な座標は反映しない。
- パーツ一覧の行、または「所属図形を選択」を実行すると、そのパーツに所属する通常図形、解決済み派生図形、自由テキスト、計測表示、縫い始め点をキャンバスで強調し、原点をオレンジ色の十字マーカーで表示する。
- 選択したパーツの所属図形をドラッグすると、パーツ全体を移動する。インスペクタの矢印ボタンでは上下左右へ10 mmずつ移動できる。
- 「パーツを複製」を実行すると、右下へ10 mmずらした複製を作成して複製先を選択する。同名になる場合は連番を付ける。
- 各パーツの「整列・等間隔の対象」を選び、2個以上で6種類の整列、3個以上で左右・上下の等間隔配置を実行できる。
- 選択パーツの「ライブラリに登録」で端末内へ保存できる。パーツライブラリには名称と必要数を表示し、配置ボタンでカーソル位置、カーソル位置がない場合は既存パーツの右側へ配置する。同名パーツがある場合は連番を付ける。
- パーツ編集欄には形状が固定されていることと、形状編集にはパーツ解除が必要であることを表示する。ロック切り替え、所属追加・除外、外形再設定は表示しない。
- 「キャンバスで位置を指定」を実行すると位置指定待ちとなり、次のキャンバスクリックへパーツ全体を移動する。位置指定待ちはボタンの再押下またはEscで取り消せる。
- パーツ選択はEscで解除できる。所属図形または所属編集用の個別図形も選択されている場合は、先に図形選択を解除し、次のEscでパーツ選択を解除する。
- 「パーツを解除」は破壊的操作として表示する。解除後も構成図形と付随要素はキャンバスに残る。

## 13. 下部サマリーとステータス

### 13.1 下部サマリー

- 下部サマリーでは、選択、拘束、パラメータの補助情報をタブまたは区画として確認できる。
- 選択がない場合は、キャンバス上の要素を選択するよう表示する。
- 拘束がない場合は、拘束なしと表示する。
- パラメータがない場合は、パラメータなしと表示する。
- パラメータ欄では、使用中/未使用の件数を表示する。

### 13.2 ステータスバー

- 直近操作の成功、失敗、キャンセル、警告を短く表示する。
- ツール切り替え時は、そのツールの待機メッセージを表示する。
- 表示補助の切り替え時は、有効/無効を表示する。
- レイヤー切り替え時は、作図レイヤー名を表示する。
- ズーム操作時は、ズーム結果と倍率を表示する。

## 14. 表示補助

- グリッド表示、A4基準表示、グリッドスナップ、点スナップをアイコン操作で切り替えられる。
- ズームイン、ズームアウト、全体表示を実行できる。
- インスペクタ、レイヤー、パラメータ、下部サマリーの表示を切り替えられる。
- パネルや補助領域の表示切り替えは主に `表示` メニューから行う。
- ツールバーの表示密度は `wide`、`regular`、`compact` のパネル配置区分ではなく、ツールバーに実際に割り当てられた幅に応じて切り替える。
- 幅が不足する場合は、コピー、貼り付け、複製、レイヤー選択、ズーム倍率、ズームイン／アウト、表示補助などの低優先項目を段階的に省略またはオーバーフローメニューへ移す。
- 編集表示／出力プレビューの切り替えは幅によって縮小せず、ツールバー上へ常に欠けのない segmented control として表示する。
- `compact` では、ツールパレットとインスペクタを drawer で開く。
- オーバーフローメニューへ移した操作も、ラベル、ショートカット、有効状態を維持する。
- `表示` メニューの `レイアウトを初期状態に戻す` で、パネル幅、表示状態、ツール区画折り畳み状態を既定へ戻せる。
- A4基準表示は作図位置確認用であり、PDF出力や印刷結果には含めない。
- メインウィンドウ上部ツールバーの表示補助グループでは、`Grid`、`A4`、A4向き、`Grid Snap`、`Point Snap` を操作できる。
- A4向きは、A4横向きのオン/オフを示す単一のトグルで切り替える。オフは縦向き、オンは横向きとして表示する。
- A4 5x5範囲内では、原点A4枠外でも作図、選択、ドラッグ、コンテキストメニュー操作を行える。A4 5x5範囲は、A4向きに合わせて縦向きまたは横向きへ切り替わる。
- 表示モードは、編集表示と出力プレビューから選択できる。
- 編集表示では、元図形、制御点、拘束マーク、計測表示、派生要素、フィレット元線分を確認・編集できる。
- 出力プレビューでは、PDF出力や直接印刷に近い解決済み形状と自由テキストを表示し、拘束マーク、制御点、選択ハイライト、グリッド、A4基準表示、計測表示、作図中プレビューは表示しない。
- 出力プレビューでは、フィレット元線分よりもトリム済み線分と円弧を主表示にする。
- 出力プレビューでは、Coreが生成した出力ページのA4境界をキャンバス上に重ね、ページ番号を各ページ左上に表示する。
- 出力プレビューでページ境界またぎなどの警告がある場合、画面下部のステータスバーに警告サマリーを表示する。
- 出力プレビューでは、キャンバス上の選択、作図、拘束追加、ドラッグ編集、コンテキストメニュー操作を行わない。
- 出力プレビュー中に作図、拘束、計測を含む編集ツールを選択すると、編集表示へ戻って選択したツールを有効にする。

## 15. 出力と印刷

### 15.1 出力設定シート

- PDF出力と直接印刷では、共通の出力設定項目を使う。
- 出力設定シートでは、出力先、A4固定、用紙向き、回転、100%実寸、総ページ数、警告、最終プレビューを同じ画面で確認できる。
- 出力前に、用紙向き、回転、寸法数値表示、50mmスケールガイドを選べる。
- 用紙向きは、現在のA4基準表示の向きを初期値として表示し、シート内で縦横を切り替えられる。
- 用紙向きを切り替えると、背後のA4基準表示も同じ向きへ更新する。
- 回転は `0°`、`90°` から選択する。
- 寸法数値表示は「寸法数値を出力に含める」として切り替える。
- 50mmスケールガイドは「50mmガイドを出力に含める」として切り替える。
- シート右側には、ページ順、ページ番号、ページ境界、印刷可能領域、貼り合わせガイドを確認できる縮小プレビューを表示する。
- 設定変更中は loading を表示し、最新の出力内容へ追従してプレビューを更新する。
- 出力対象がない場合は、PDF出力設定を開いた時点で総ページ数を `0ページ` と表示し、出力対象がない警告を表示する。
- PDF出力では「保存へ進む」、直接印刷では「印刷へ進む」を確定操作として表示する。

### 15.2 PDF出力

- PDF出力メニューから設定シートを開く。
- 設定確定後、PDF保存先を選択する。
- 出力に成功した場合、保存先または成功メッセージを表示する。
- PDF生成に失敗した場合は保存せず、エラーを表示する。

### 15.3 直接印刷

- 直接印刷メニューから macOS 標準の印刷設定を開き、プリンタ、A4、倍率、印刷可能領域を選ぶ。
- 印刷設定確定後、その設定を使った最終確認シートを開く。
- 最終確認シートでは、プリンタ名、印刷可能領域、警告、プレビューを確認した上で印刷へ進む。
- 最終確認シートから OS 印刷設定を開き直して、プリンタや余白を更新できる。
- 印刷用データ生成に失敗した場合は、直接印刷を開始しない。

### 15.4 警告

- 空ドキュメント、印刷可能領域からのはみ出し、実寸未保証は警告として表示する。
- 続行可能な警告は、最終確認シート内へ一覧表示する。
- 警告がある場合は、「警告内容を確認しました」を明示するまで保存または印刷ボタンを無効にする。
- 警告確認専用の別ダイアログは表示しない。

## 16. エラーと警告の扱い

- 操作を完了できない場合は、共通のアラートまたはステータス表示で理由を示す。
- Coreプロセス未接続、起動失敗、終了、レスポンス不正は、Core接続に関するエラーとして表示する。
- 不正な入力値は、値の範囲や形式を確認するよう表示する。
- 参照切れは、対象が削除されていないか確認するよう表示する。
- 出力ページが生成されない、不正なページサイズ、不正な回転角、PDF/印刷データを解釈できない場合は、出力対象または設定を確認するよう表示する。
- エラー表示後も、利用者が現在のドキュメント状態を確認できるようにする。
- 未保存変更がある間は、macOS 標準の編集済み表示をウィンドウに出す。
- 保存済み文書のウィンドウタイトルはファイル名を主識別子にし、内部のプロジェクト名が異なる場合は `ファイル名 — プロジェクト名` と表示する。実質同名の場合はファイル名だけを表示する。
- 未保存文書のタイトルは `プロジェクト名 — 未保存` とする。ウィンドウのVoiceOverラベルでは、ファイル名（ある場合）、プロジェクト名、未保存／保存済み、変更ありを区別して伝える。
- 新規作成、別ファイルを開く、ウィンドウを閉じる、終了する前に未保存変更がある場合は、ドキュメントモーダルの保存確認シートを表示する。
- 保存確認シートでは、保存、変更内容を破棄、キャンセルを選べる。
- 最後のウィンドウを閉じるために `変更内容を破棄` を選んだ場合、続くアプリケーション終了で保存確認シートを再表示しない。
- `変更内容を破棄` は破壊的操作として視覚とVoiceOverの両方で区別する。
- 自動復旧の保存に失敗した場合は、ツールバー直下に非モーダルの banner を表示し、再試行と詳細表示を選べる。
- 起動時に自動復旧候補がある場合は、候補一覧シートを1枚だけ表示し、復旧して開く、破棄、後で、Finderに表示を選べる。
- ツールパレットは基本表示から始め、利用者が詳細表示へ切り替えると詳細ツールを追加表示する。
- 狭い画面では、主要操作を残したまま低優先の操作をオーバーフローメニューへ移し、ツールとインスペクタは drawer または overlay から到達できる。

## 17. アクセシビリティとローカライズ

- キャンバスは固定のアクセシビリティ識別子とラベルを持ち、現在のツール、表示モード、図形数、選択数、拘束対象選択数、進行中操作を高水準の状態として公開する。
- キャンバスのアクセシビリティ状態は読み取り専用であり、通常の作図・編集操作を迂回してドキュメントを変更する機能を持たない。
- ツールバーの主要なパネル操作、ズーム、表示補助、用紙向き、スナップ、表示モードには固定識別子を付ける。オン・オフを持つ項目はラベルと現在値を分けて公開する。
- ステータスバーは、画面上の表示内容をまとめたラベルと現在値を公開する。
- パネル幅変更には操作名と操作方法のヒントを付ける。
- `変更内容を破棄` は、VoiceOverでも破壊的操作と判別できるラベルを持つ。
- 利用者向けの主要文言は日本語リソースを経由し、内部 ID や通信上のエラーコードをそのまま表示しない。

レイヤー操作など、現在も詳細化が必要な読み上げ表現は、現行仕様として本節へ固定せず [`../backlog/open-questions.md`](../backlog/open-questions.md) で管理する。

## 18. Apple デザインガイドとの対応

| 対象                     | 方針                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 上部ヘッダとツールバー   | 頻用コマンド、状態表示、表示切り替えを細い上部バーへまとめる |
| ツールパレット           | 長い一覧ではなく、補助的なツール群をコンパクトに見せる       |
| 表示メニュー             | パネルや補助領域の表示切り替えを集約する                     |
| 下部サマリー             | 主作業領域より目立たない補助情報として扱う                   |
| サイドバーとインスペクタ | macOS 標準 material に近い軽い境界表現を使う                 |
| 文字色                   | 主要ラベルと補助ラベルを semantic color で見分ける           |
| アイコン                 | 操作種別が分かるシステムアイコンまたは専用アイコンを使う     |
