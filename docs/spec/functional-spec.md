# 機能仕様書

## 1. 目的

本書は、利用者が観測できる KawaCAD の機能仕様を定義する。

利用者が何をできるか、どの条件で成功・失敗するか、保存・読み込みや出力で何が再現されるかを扱う。画面構成、操作導線、ショートカット、視覚フィードバック、文言は `docs/spec/ui-ux-spec.md` に置く。内部実装や作業手順は扱わない。

## 2. 対象範囲

KawaCAD は、革小物の型紙を正確に作図、編集、保存、再利用、出力するためのパラメトリック 2D CAD である。利用者は図形を自由に作図し、拘束、寸法、派生要素、レザークラフト固有の意味情報、パーツを組み合わせて型紙を構成する。

保存・読み込み、編集結果、出力結果は、同じ入力と設定に対して再現可能である。アプリケーションは端末内で利用でき、プロジェクトや補助データを利用者の明示なく外部へ送信しない。外部サービスへの同期やオンライン接続は機能成立の条件ではない。

共通の編集機能と出力プレビューは次の UI で提供する。PDF 生成と直接印刷は Swift/macOS UI の機能に限り、Tauri/React UI には含めない。

| UI | 対応環境 | 編集 | 出力 |
| --- | --- | --- | --- |
| Swift/macOS | macOS 13 以降 | 全機能 | PDF 出力、macOS の直接印刷、出力プレビュー |
| Tauri/React | Windows・Linux・macOS | 全機能 | 出力プレビュー。PDF 生成と直接印刷は対象外 |

本書の対象は、CAD 基盤、レザークラフト固有要素、パーツ管理、保存、出力プレビュー、および Swift/macOS における PDF 出力と直接印刷である。

| 領域                   | 利用者ができること                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| プロジェクト           | 新規作成、保存、別名保存、読み込み、再読込、プロジェクト名変更                             |
| 基本作図               | 点、線分、円、円弧、中心線の作成・編集・削除                                               |
| 基本編集               | 全選択、コピー、ペースト、位置指定ペースト、複製、ドラッグ移動、削除                       |
| 拘束                   | 幾何拘束、寸法拘束、固定拘束、対称拘束の追加・更新・削除                                   |
| パラメータ             | 名前付きパラメータの作成・編集・削除、寸法拘束と派生要素からの参照                         |
| 計測表示               | 形状を駆動しない寸法・角度の補助表示、保存・読み込み、Undo/Redo、拘束への変換              |
| 派生要素               | 元図形に追従するオフセット線とフィレットの作成・編集・削除・保存・読み込み                 |
| 履歴                   | Undo/Redo、Redo履歴の破棄、複合操作の単一履歴化                                            |

| パーツ                 | 閉じた外形からの作成、形状固定、選択、位置変更、複製、解除、保存・読み込み、複数パーツ出力 |
| 表示補助               | グリッド、A4基準表示、スナップ、ズーム、拘束マーク                                         |
| 出力                   | A4固定・100%実寸のPDF出力と直接印刷。A4単位の複数ページ出力を含む                          |

## 3. 基本仕様

### 3.1 作図座標と単位

- 作図座標はミリメートル単位で扱う。
- 原点は用紙中心である。
- X正方向は右、Y正方向は上である。
- 作図可能範囲は、原点を含むA4ページを中心にしたA4 5x5相当の範囲であり、A4基準表示の向きに追従する。
- 図形座標は画面ピクセルではなく作図座標として保持される。
- 保存・読み込み後も、同じ `.lcraft` ファイルは同じ作図座標として復元される。
- 角度寸法で利用者が指定する値は度数法で扱う。
- 円弧の内部表現に由来する開始角・掃引角は、表示・編集時に利用者が理解できる角度として扱う。

### 3.2 成功・失敗時の共通ルール

- 成功した編集だけがドキュメントへ反映される。
- 失敗した編集では、変更前の作図内容、拘束、パラメータ、レイヤー状態を維持する。
- 不正な ID、重複 ID、参照切れ、不正な数値、不正な拘束対象、既存拘束との競合は拒否される。
- 拘束または派生要素の参照先が削除される場合、維持できない関連情報は整理され、必要に応じて警告される。
- 表示補助の切り替え、ズーム、パン、パネル表示状態は作図内容を変更しない。

## 4. プロジェクト

### 4.1 新規作成

- 新規作成後は空の作図状態から編集を開始できる。
- 新規ドキュメントには、既定のカット線レイヤーが存在する。
- 新規ドキュメントは `.lcraft` 形式として保存できる。

### 4.2 保存・読み込み・再読込

- プロジェクトは `.lcraft` JSON ファイルとして保存できる。
- 保存対象には、プロジェクト名、単位、印刷設定、レイヤー、共有スタイル、図形、派生要素、自由テキスト、丸穴、縫い始め点、拘束、パラメータ、パーツ、計測表示、寸法拘束の表示位置を含む。
- 保存、新規作成、既存ファイルを開く操作を開始する前に、プロジェクト名の有効な編集中値を保存対象へ反映する。名称が無効な場合は、対象操作を開始しない。
- UI の一時状態、選択状態、ズーム倍率、パネル開閉状態は保存対象ではない。
- 保存対象が最後に保存または読み込みした内容と異なる間は、未保存変更ありとして扱う。
- 新規作成、既存ファイルを開く、ウィンドウを閉じる、アプリケーションを終了する前に、未保存変更がある場合は保存確認を行う。
- 保存確認では、保存、変更内容を破棄、キャンセルを選べる。
- 保存パネルをキャンセルした場合や保存に失敗した場合は、元のドキュメントと編集中状態を維持する。
- ファイル名とプロジェクト名は独立して保持する。保存済み文書はファイル名を主識別子とし、プロジェクト名が異なる場合は両方をウィンドウで識別できる。
- 変更内容を破棄して別のドキュメントへ切り替える操作が失敗した場合も、元のドキュメントと自動復旧データを維持する。
- `.lcraft` ファイルを開くと、保存されていた印刷設定、レイヤー、共有スタイル、図形、派生要素、自由テキスト、丸穴、縫い始め点、拘束、パラメータ、パーツ、計測表示、寸法拘束の表示位置を復元する。
- 読み込みに失敗した場合、現在編集中の作図内容は維持される。
- 再読込では、現在のドキュメントセッションから最新状態を取得し、表示状態を更新できる。
- 異常終了に備えて、自動復旧用のスナップショットを通常保存先とは別に保持する。
- 次回起動時に有効な自動復旧データがあれば、復旧して開く、破棄、後で確認する、を選べる。
- 自動復旧から開いた内容は未保存状態として扱い、利用者が明示的に保存するまで元ファイルを自動上書きしない。

### 4.3 プロジェクト名

- プロジェクト名を変更できる。
- 空または不正なプロジェクト名は拒否される。
- 変更後のプロジェクト名は保存対象になる。

### 4.4 アプリケーション終了

- 最後のドキュメントウィンドウを閉じると、アプリケーションは終了する。
- 未保存変更がある状態でウィンドウを閉じる、または終了する場合は、保存確認を完了してから終了可否を決める。
- 最後のウィンドウを閉じる際に変更内容を破棄した場合は、その終了に伴うアプリケーション終了で保存確認を繰り返さない。
- 保存確認をキャンセルした場合や保存に失敗した場合は、ウィンドウもアプリケーションも終了しない。

### 4.5 端末内の補助データ

- 自動復旧データは `~/Library/Application Support/KawaCAD/Recovery/` に保存し、更新から30日を超えたものを整理する。保持するドキュメント候補は最大10件で、各候補は最新世代を保持する。
- パーツライブラリは `~/Library/Application Support/KawaCAD/part-library.json` に保存する。利用者はアプリ内で登録済み項目を削除できる。
- 自動復旧とパーツライブラリは自動で外部送信しない。
- 自動復旧候補は復旧選択画面から破棄できる。

## 5. 基本作図

### 5.1 対応図形

| 図形   | 作成・保持される内容       | 主な用途               |
| ------ | -------------------------- | ---------------------- |
| 点     | 1つの作図座標              | 拘束、寸法、参照点     |
| 線分   | 始点と終点                 | 外形、基準線、寸法対象 |
| 円     | 中心と半径                 | 丸穴、円形基準         |
| 円弧   | 中心、半径、開始角、掃引角 | 角丸、曲線外形         |
| 中心線 | 始点と終点を持つ補助線     | 対称軸、基準線         |

- 線分と中心線は、始点と終点が同一または実質的にゼロ長になる場合は作成・更新できない。
- 円と円弧は正の半径を必要とする。
- 円弧はゼロではない掃引角を必要とする。
- 中心線は通常図形と同様に選択、拘束、寸法対象として扱える。

### 5.2 円弧

- 円弧は `中心 -> 開始点 -> 終点` の順で作成する。
- 開始点は中心と異なる位置でなければならない。
- 終点は開始点と異なる角度を作る位置でなければならない。
- 円弧の掃引角は、正方向・負方向とも 180 度を超える値を保持できる。
- ゼロ掃引角または 360 度ちょうどに相当する掃引角は作成対象にしない。
- 作成直後の円弧は、開始角と掃引角を編集できる。
- 別の円弧を作成または選択した後に、直前の円弧の未確定編集値を新しい円弧へ適用しない。
- 円弧の中心、開始角、終了角は、選択・計測・拘束に使う制御点として扱える。
- 円弧の半径、直径、掃引角は寸法拘束または計測表示の対象にできる。

### 5.3 中心線

- 中心線は、通常の線分とは異なる補助線として表示できる。
- 中心線は対称拘束の軸として使える。
- 中心線は線分系拘束、線分間距離拘束、点/制御点の直線上拘束、オフセット線、フィレットの対象にできる。
- 中心線は出力対象に含めることができる。ただし、非表示または印刷対象外レイヤー上の中心線は出力されない。

## 6. 基本編集

### 6.1 選択

- 図形、制御点、拘束マーク、計測表示を選択できる。
- 複数の図形を選択できる。
- 空白クリックで選択解除できる。
- 制御点と図形本体が近接する場合、制御点が優先的に選択される。
- 拘束追加中は、選択中の拘束で有効な対象種別が優先される。

### 6.2 コピー・ペースト・複製

- 選択中の図形、派生要素、拘束、計測表示、縫い始め点、自由テキストをコピー対象にできる。
- コピー時は、選択した対象を根として、成立に必要な図形、拘束、注釈、派生要素などの依存関係を含む転送用スナップショットを生成する。
- コピー済みスナップショットを、同じ Core 互換バージョンのドキュメントへペーストできる。
- ペースト時に編集可能なキャンバス上のカーソル位置が利用できる場合、コピー対象の外接矩形中心をその位置へ合わせて配置できる。位置を利用できない場合、またはコピー元や直前の結果と重なる場合は、コピー元または直前の結果からX/Y各5 mmずつずらして配置する。
- ペースト直後は、カーソル位置とコピー元付近の配置方式を切り替えられる。切替は余分な複製を残さず、ペースト全体で1回の Undo/Redo 単位として扱う。
- 複製とペーストでは、対象と依存関係へ元とは異なる ID を割り当て、参照を複製先へ付け替える。
- 複数対象をコピー、ペースト、複製でき、各操作は1回の Undo/Redo 単位になる。
- 外部参照、ID 衝突、不正な転送用スナップショットがある場合は操作全体を拒否し、部分的な複製を残さない。

### 6.3 ドラッグ移動と複製

- 選択中のエンティティをドラッグ移動できる。
- 拘束で接続された図形をドラッグする場合、関連図形は拘束を満たす範囲で連動する。
- ドラッグ中はプレビューとして扱い、確定するまでは正式な変更にならない。
- `Option` + ドラッグでは、元図形を残したまま複製を作成できる。
- 複数エンティティのドラッグ移動と `Option` + ドラッグ複製は、1回の Undo/Redo 単位として扱う。
- 単一の線分または中心線の全体移動が拘束で解けない場合、片方の端点だけを動かす伸縮として解けるなら、その伸縮を適用できる。
- 線分または中心線の端点ドラッグが拘束で解けない場合、元の線分方向へ射影した伸縮として解けるなら、その伸縮を適用できる。
- 解けない移動や未対応対象のドラッグは拒否され、ドラッグ前の状態を維持する。
- 3本以上を元にしたフィレットの元線分をドラッグした場合、選択した元線分をドラッグ対象とし、フィレット全体の元線分集合へ自動拡張しない。

### 6.4 削除

- 選択中の図形、拘束、計測表示を削除できる。
- 複数エンティティの削除は、1回の Undo/Redo 単位として扱う。
- 図形を削除すると、その図形に依存する拘束、派生要素、計測表示は維持可否を再評価する。
- 削除対象の元図形だけから成るフィレットは、警告なしで同時に削除される。
- レイヤー削除時の扱いは 11.5 に従う。

## 7. 拘束

### 7.1 対応拘束

| 種別     | 対象                                 | 成立すること                                                                 |
| -------- | ------------------------------------ | ---------------------------------------------------------------------------- |
| 一致     | 点または制御点2件                    | 2点を同じ位置に保つ                                                          |
| 水平     | 線分系対象または点ペア               | 対象を水平に保つ                                                             |
| 垂直     | 線分系対象または点ペア               | 対象を垂直に保つ                                                             |
| 平行     | 線分系対象2件                        | 2本の方向を平行に保つ                                                        |
| 直交     | 線分系対象2件                        | 2本の方向を直交に保つ                                                        |
| 接線     | 接続済みの線分系端点1件と円弧端点1件 | 線分の反対端点から接続点へ進み、そのまま円弧へ入る向きで接線方向を一致させる |
| 同長     | 線分系対象2件                        | 2本の長さを一致させる                                                        |
| 固定     | 点または制御点                       | 対象点を現在位置に固定する                                                   |
| 対称     | 点/制御点2件と線分系対象1件          | 2点を軸に対して対称に保つ                                                    |
| 直線上   | 点/制御点1件と線分系対象1件          | 点を支持直線上に保つ                                                         |
| 2点距離  | 点/制御点2件                         | 2点間距離を指定値に保つ                                                      |
| 水平距離 | 点/制御点2件                         | 2点間のX方向距離を指定値に保つ                                               |
| 垂直距離 | 点/制御点2件                         | 2点間のY方向距離を指定値に保つ                                               |
| 点線距離 | 点/制御点1件と線分系対象1件          | 点と支持直線の垂直距離を指定値に保つ                                         |
| 線線距離 | 線分系対象2件                        | 支持直線間の垂直距離を指定値に保ち、平行性も保つ                             |
| 線分長   | 線分系対象1件                        | 線分長を指定値に保つ                                                         |
| 角度     | 共有端点を持つ線分2件、または円弧1件 | 角度または円弧掃引角を指定値に保つ                                           |
| 直径     | 円1件                                | 直径を指定値に保つ                                                           |
| 半径     | 円または円弧1件                      | 半径を指定値に保つ                                                           |

線分系対象には、線分、中心線、および仕様上対応する線分相当の対象を含む。対称拘束では、線分または中心線を対称軸として扱う。

### 7.2 寸法値とパラメータ参照

- 距離、水平距離、垂直距離、点線距離、線線距離、線分長、直径、半径、オフセット距離、フィレット半径は、固定ミリメートル値または名前付きパラメータ参照を指定できる。
- 角度拘束は固定度数法値を指定する。
- 寸法値は正の有限値でなければならない。
- 角度値は有限の度数法値でなければならない。
- パラメータを参照した拘束や派生要素は、パラメータ値の変更に追従する。

### 7.3 角度拘束

- 2線分の角度拘束では、2本の線分が端点を共有している必要がある。
- 角度は、共有端点から1本目の反対端点へ向かう方向を基準に、共有端点から2本目の反対端点へ向かう方向までの符号付き角度として扱う。
- 正の角度は作図座標系上で反時計回り、負の角度は時計回りである。
- 円弧の角度拘束では、円弧の掃引角を符号付き角度として扱う。
- 端点を共有しない2線分への角度拘束は拒否される。

### 7.4 接線拘束

- 接線拘束では、線分または中心線の始点/終点と、円弧の開始点/終了点を対象にする。
- 対象端点は同じ位置にあるか、一致拘束により同じ論理点として接続されている必要がある。
- 接線拘束は、線分または中心線の反対端点から接続点へ進み、そのまま円弧へ入る向きで接線方向を一致させる。
- 円弧の開始点で接続する場合は、線分から接続点へ向かう方向を円弧開始点の接線方向に合わせる。
- 円弧の終了点で接続する場合は、線分から接続点へ向かう方向を円弧終了点から円弧内部へ戻る接線方向に合わせる。
- 線分または中心線の方向を変更した場合、円弧は接続点で滑らかに接続するよう再評価される。
- 接続していない対象、対象不足、線分系対象と円弧以外の組み合わせは拒否される。
- 試作導線として、選択中の円弧が両端で2本の線分または中心線と接続済みの場合、円弧と接続線分を両端で滑らかに接続する形へ更新し、必要な接線拘束を追加できる。

### 7.5 拘束状態

- 拘束状態は、拘束単位、エンティティ単位、ドキュメント単位で確認できる。
- 状態には、未評価、拘束不足、完全拘束、冗長拘束、競合がある。
- 拘束追加、拘束更新、拘束削除、寸法変更、パラメータ変更後は、関係する拘束状態が再評価される。
- 解が存在しない変更、対象不足、不正対象、重複、参照切れは拒否され、変更前状態が維持される。

### 7.6 拘束削除・更新

- 追加済み拘束は削除できる。
- 削除後、関連する拘束状態は再評価される。
- 寸法拘束の値は、固定値またはパラメータ参照として更新できる。
- 寸法拘束の値を更新しても、対象の種類は変わらない。
- 寸法拘束の表示位置は、拘束本体とは分離した補助表示情報として保持できる。
- 寸法拘束のラベル位置と表示全体位置は、`.lcraft` の保存・読み込みで再現でき、位置更新を Undo/Redo できる。
- 寸法拘束の表示位置を変更しても、拘束値、拘束 target、図形形状、拘束評価は変わらない。

## 8. パラメータ

### 8.1 名前付きパラメータ

- パラメータは、名前とミリメートル値を持つ。
- パラメータは追加、編集、削除できる。
- パラメータ名と値は一覧で確認できる。
- パラメータ名はプロジェクト内で一意でなければならず、同名の追加または変更は拒否される。
- パラメータ値は有限の数値でなければならない。

### 8.2 参照と使用状況

- 寸法拘束、オフセット距離、フィレット半径はパラメータを参照できる。
- パラメータを変更すると、参照している拘束や派生要素が再評価される。
- パラメータ一覧では、使用中/未使用の状態を確認できる。
- パラメータ削除時には、参照していた拘束を削除時点の値に相当する固定値へ置き換えられる。
- パラメータ削除または値変更で拘束や派生要素を維持できない場合、変更は拒否される。

## 9. 計測表示

### 9.1 対応する計測表示

| 種別       | 対象                  | 表示値       |
| ---------- | --------------------- | ------------ |
| 距離表示   | 点/制御点2件          | 2点間距離    |
| 線分長表示 | 線分系対象1件         | 線分長       |
| 角度表示   | 共有端点を持つ線分2件 | 符号付き角度 |
| 半径表示   | 円または円弧1件       | 半径         |
| 直径表示   | 円または円弧1件       | 直径         |
| 円弧角表示 | 円弧1件               | 掃引角       |

### 9.2 計測表示の性質

- 計測表示は形状を駆動しない。
- 計測表示は拘束、パラメータ、自由度評価、派生要素の解決に影響しない。
- 計測表示の値は保存せず、表示時に対象図形から再計算する。
- 計測表示は `.lcraft` の保存・読み込みで再現できる。
- 計測表示は追加、位置更新、削除を Undo/Redo できる。
- 計測表示には、ラベル位置と表示全体位置の補正を保持できる。
- 参照対象が削除された計測表示は、図形本体や拘束評価を壊さず整理され、警告対象になる。
- 派生要素は計測表示の対象外である。ただし、フィレット解決済み線分を選んだ場合、対応する元線分を対象として扱える範囲がある。

### 9.3 拘束への変換

- 計測表示は、対応する寸法拘束または角度拘束へ変換できる。
- 変換時は、現在の実測値を初期値として拘束を追加する。
- 変換に成功すると、元の計測表示は削除される。
- 変換に失敗した場合、元の計測表示と図形状態は維持される。

## 10. 派生要素

### 10.1 共通仕様

- 派生要素は、元図形に追従する作図要素である。
- 派生要素は、作成時点の通常図形へ固定されない。
- 派生要素は `.lcraft` に保存され、読み込み後に元図形から解決済み形状として再生成される。
- 派生要素は通常の選択対象として扱える。
- 派生要素は初期実装では拘束の target として扱わない。
- 循環参照は拒否される。
- 元図形の削除、参照元の削除、または元図形変更によって維持できなくなった派生要素は削除され、警告対象になる。

### 10.2 オフセット線

オフセット線は、元図形から指定距離だけ離れた位置に生成され、元図形の変更に追従する派生要素である。

| オフセット元                                               | 作成されるオフセット線                               |
| ---------------------------------------------------------- | ---------------------------------------------------- |
| 線分、中心線、円弧のいずれか1つ                            | 元図形の片側にある、指定距離の図形                   |
| 円                                                         | 円の内側または外側にある、同心円                     |
| ユーザーが選択した、端点のつながる複数の線分、中心線、円弧 | 選択した連続区間だけに沿った、一続きの図形           |
| 線分、中心線、円弧で構成された閉じた輪郭                   | 輪郭の内側または外側にある、一周分の図形             |
| フィレット適用後の形状から選択した連続区間                 | フィレットの線分と円弧を保った、選択区間だけの図形   |
| フィレット適用後の閉じた輪郭                               | フィレット適用後の形状を基準にした、一周分の図形     |
| 既存のオフセット線                                         | そのオフセット線を基準にした、さらに別のオフセット線 |

- オフセット距離は、正の有限なミリメートル値または名前付きパラメータ参照で指定する。
- 単独の線分、中心線、円弧、または開いた連続線では、元図形のどちら側に作成するかを指定できる。
- 円または閉じた輪郭では、内側と外側のどちらに作成するかを指定できる。
- 接続する複数の元図形から一部を選択した場合、選択した連続区間だけをオフセット元とし、隣接する未選択図形は自動的に追加しない。
- フィレットの元線分を部分選択した場合は、選択線分に対応するトリム済み線分と、その間をつなぐフィレット円弧だけをオフセット元にする。
- フィレットの円弧と隣接線分が接する部分では、オフセット後も接線接続を維持し、不要な折れや外側への回り込みを生成しない。
- 選択した連続区間の両端は閉じず、生成されたオフセット線の端点として扱う。
- 閉じた輪郭の線分同士の角は、隣接するオフセット線分の交点で接続する。
- 閉じた輪郭をオフセット元にしても、輪郭を構成する元図形は個別に編集できる状態で保たれる。
- オフセット線は、元図形または参照パラメータが変わると再生成される。
- 表示、保存・読み込み、Undo/Redo、出力では、元図形と指定値から再生成された同じ形状を扱う。
- 作成済みオフセット線は、距離、方向、レイヤーを変更できる。
- 距離がゼロ、負数、または有限でない場合、オフセット線の作成・更新は拒否され、変更前の状態が維持される。

### 10.3 フィレット

- 接続する2本以上の線分または中心線、または接続する1本の線分もしくは中心線と1つの円弧を元に、指定半径のフィレットを作成できる。
- 2本を指定した場合は、その2本がなす共有角だけをフィレットする。
- 線分または中心線と円弧の2本を指定した場合は、両方をトリムして共有角を接線接続する。
- 3本以上の開いた連続パスを指定した場合は、内部頂点をまとめてフィレットする。
- 3本以上の閉じた線分輪郭を指定した場合は、全頂点をまとめてフィレットする。
- 複数選択によるフィレットでは、選択した順序にかかわらず、接続する元図形を同じ連続順として扱う。
- フィレット元の線分、中心線、または円弧は、フィレットツール選択後にクリックで収集できる。円弧を含む指定は、接続する線分または中心線との2本だけを対象にする。
- 既存フィレットに隣接する角へフィレットを追加する場合は、既存フィレットの元図形列を拡張して扱う。
- 既存フィレットの拡張で参照元列が幾何的に閉じても、ユーザーが閉じた輪郭全体を選択していない場合は開いたパスとして扱い、未選択の角はフィレットしない。
- フィレット半径は、固定ミリメートル値または名前付きパラメータ参照で指定できる。
- 作成済みフィレットの解決済み円弧を選択した場合、フィレット半径を変更できる。
- フィレットは、元線分、元中心線、元円弧、または参照パラメータの変更に追従する。
- 同一線分の両端にフィレットがかかる場合、その線分は両端をトリムした1本の解決済み線分として表示する。
- キャンバス表示では、元線分、元中心線、または元円弧に加えて、トリム済み図形と円弧を解決済み図形として表示する。
- 出力では、フィレットの参照元となった通常線分、中心線、または円弧を除外し、トリム済み図形とフィレット円弧だけを出力する。
- 半径が大きすぎる、参照元が接続していない、または参照元の組み合わせが未対応の場合、フィレット作成は拒否され、変更前状態が維持される。

## 11. レイヤーとスタイル

### 11.1 レイヤー種別

| 種別       | 用途                             |
| ---------- | -------------------------------- |
| カット線   | 型紙外形など主要な実線形状       |
| 寸法       | 寸法表示用の補助要素             |
| 印刷ガイド | スケール確認や位置合わせのガイド |
| 補助線     | 作図補助、基準線                 |

### 11.2 表示と印刷対象

- レイヤー名はプロジェクト内で一意でなければならず、同名の追加または名前変更は拒否される。
- レイヤーごとに表示/非表示を切り替えられる。
- 非表示レイヤーの要素と、その要素に由来する派生表示はキャンバスに表示しない。
- レイヤーごとに印刷対象/非対象を切り替えられる。
- 補助線レイヤーは印刷対象にできない。
- 非表示レイヤーの要素は、出力対象から除外される。
- 派生要素の出力では、派生要素自身と参照元の表示状態および印刷対象状態を考慮する。

### 11.3 線スタイル

- レイヤーごとの線色、線幅、線種を変更できる。
- 線種は実線、破線、点線、補助線を扱える。
- 線幅は正の値でなければならない。
- 線色は不透明度を含む色として保持される。
- 線スタイル変更は、図形座標、拘束、パラメータを変更しない。

### 11.4 共有スタイル

- プロジェクト内に共有スタイルを追加、編集、削除できる。
- 共有スタイルは、名前、線色、線幅、線種を持つ。
- 新規プロジェクトには、外形カット線、縫い線、折り線、中心線、補助線、寸法線の共有スタイルが初期登録される。
- 図形と派生要素には共有スタイルを適用できる。共有スタイルを未設定に戻すこともできる。
- 作図時に選択中の共有スタイルは、線分、円弧、中心線、水平中心線、垂直中心線へ適用される。
- オフセット線を作成する場合、選択中の共有スタイルは作成されたオフセット派生要素へ適用される。
- 同じ共有スタイルを参照する複数の図形または派生要素がある場合、共有スタイルの変更は対象の表示と出力に一括反映される。
- 図形または派生要素に共有スタイルが設定されている場合、表示と出力では共有スタイルを優先する。共有スタイルが未設定の場合は、従来どおりレイヤーの線スタイルを使う。
- 共有スタイルと図形・派生要素への適用状態は、保存・読み込み後も再現される。
- 共有スタイルを削除した場合、図形と派生要素は削除されず、共有スタイル未設定として扱われる。

### 11.5 レイヤー削除

- レイヤーを削除できる。
- 最後の1レイヤーは削除できない。
- 存在しないレイヤーの削除は拒否される。
- 図形が紐づくレイヤーを削除する場合、確認後に対象図形は残りのレイヤーへ移動する。
- レイヤー削除後も、図形、拘束、パラメータの意味は維持される。

## 12. 型紙要素

### 12.1 自由テキスト

- ユーザーは、型紙上に自由テキスト注記を配置できる。
- 自由テキストは、表示文字列、基準位置、文字サイズを持つ。
- 自由テキストの内容、位置、文字サイズを編集できる。
- 自由テキストを削除できる。
- 自由テキストは保存・読み込み対象であり、読み込み後に文字列、位置、文字サイズを再現する。
- 自由テキストは出力プレビュー、PDF出力、直接印刷に含まれる。
- 寸法ラベル、50mmガイドラベル、自由テキストは用途として区別される。
- 空文字、不正な位置、正の有限値ではない文字サイズは拒否され、既存状態は変更されない。
- 自由テキストは拘束 target にはならず、拘束状態や自由度評価を駆動しない。

### 12.2 丸穴

- ユーザーは、型紙上に丸穴を配置できる。
- 丸穴は、キーリング穴、カシメ穴、ジャンパーホック穴、装飾穴のいずれかの穴種別を持つ。
- 丸穴は円形状として表示され、中心位置、直径、レイヤー、共有スタイルを持つ。
- 作図時に選択中の共有スタイルは、新しく配置する丸穴へ適用される。
- 丸穴の穴種別と直径は後から編集できる。
- 丸穴の中心位置は、選択ツールによる通常図形の移動と同じ操作で変更できる。
- 丸穴と穴種別は保存・読み込み対象であり、読み込み後に中心位置、直径、共有スタイル、穴種別を再現する。
- 丸穴は出力プレビュー、PDF出力、直接印刷に円形状として含まれる。穴種別名は出力しない。
- 正の有限値ではない直径、存在しない参照先、円以外の図形を参照する丸穴は拒否され、既存状態は変更されない。
- 丸穴の参照先円図形を削除した場合、対応する丸穴も削除される。

### 12.3 縫い始め点

- ユーザーは、縫い線上に縫い始め点を配置できる。
- 縫い始め点の対象にできるのは、共有スタイル「縫い線」を参照する線分、中心線、円弧、またはそれらとして解決されるオフセット線である。
- 縫い始め点は対象縫い線との関係と、対象線上の位置として保持される。
- 対象縫い線が拘束、パラメータ、または派生要素の再解決で変化した場合、縫い始め点の表示位置と出力位置も追従する。
- 縫い始め点は保存・読み込み対象であり、読み込み後に対象縫い線との関係と線上位置を再現する。
- 縫い始め点は出力プレビュー、PDF出力、直接印刷に識別可能な点 marker として含まれる。
- 縫い線ではない図形、存在しない対象、線分/中心線/円弧として解釈できない対象、範囲外の線上位置は拒否され、既存状態は変更されない。
- 縫い始め点の対象図形または対象派生要素を削除した場合、対応する縫い始め点も削除される。

## 13. 表示・操作補助

### 13.1 グリッド・A4基準・ズーム

- グリッド表示、A4基準表示、グリッドスナップ、点スナップを切り替えられる。
- A4基準表示は作図位置確認用であり、原点固定のA4 5x5グリッドとして表示する。縦向きと横向きを切り替えられ、作図可能範囲も同じ向きへ切り替わる。PDF出力や印刷結果には含めない。
- ズームイン、ズームアウト、全体表示を実行できる。
- ズームやパンは作図内容を変更しない。
- 画面幅が狭い場合でも、ズーム、表示モード、表示補助の主要操作はツールバーまたはオーバーフローメニューから利用できる。

### 13.2 スナップと自動拘束

- スナップは入力補助であり、確定後の図形座標または拘束だけがドキュメントへ反映される。
- 既存点へスナップした線分端点には、一致拘束を自動付与できる。
- 水平または垂直に近い線分には、水平拘束または垂直拘束を自動付与できる。
- Shift補正では、線分や円弧の作図角度を補正できる。
- グリッドスナップだけで確定した場合、拘束は自動付与しない。
- `Control` キー押下中は、作図中とドラッグ中のスナップを一時的に無効化できる。

### 13.3 拘束マーク

- 拘束マークは、対象図形または制御点の近くに表示される。
- 拘束マークから対応する拘束を選択できる。
- 複数の拘束マークが近接する場合、重なりを避けて並べられる。
- 拘束マークの表示は出力対象に含めない。

### 13.4 表示モード

- 編集表示では、通常編集用の図形、派生要素、拘束状態を確認できる。
- 出力プレビューでは、PDF出力や直接印刷に近い解決済み形状を確認できる。
- 出力プレビューでは、フィレットの参照元となった通常線分または中心線を除外し、トリム済み線分と円弧を表示する。
- 出力プレビューでは、非表示レイヤーまたは印刷対象外レイヤーの要素を表示対象から除外する。
- 出力プレビューでは、出力用中間表現のページ分割結果に基づいて、A4ページ境界とページ番号を確認できる。
- 出力プレビューでは、ページ境界またぎなどの出力警告を画面下部のサマリーで確認できる。
- 出力プレビュー中に作図、拘束、計測を含む編集ツールを選択すると、編集表示へ戻ってから選択したツールを有効にする。
- 表示モードの切り替えは作図内容を変更せず、Undo/Redo 履歴に追加されない。
- 現行仕様では、閉じた輪郭を独立した永続エンティティや閉領域として扱わない。
- 低優先の表示補助や編集操作は、画面幅に応じてオーバーフローメニューへ退避しても利用できる。

## 14. パーツ管理

### 14.1 作成と成立条件

- 1つのプロジェクトに複数のパーツを作成できる。
- 選択した図形が1つの閉じた外側ループを作る場合、その選択からパーツを作成できる。
- 外側ループの内側にある閉じたループは穴として扱う。外側ループの外に別の閉じたループがある選択や、外形が閉じていない選択からは作成できない。
- 各パーツは重複しない名称と、ミリメートル単位の配置基準点を持つ。名称は作成後に変更でき、配置基準点はパーツ全体の移動によって変更される。
- 同じ図形を複数のパーツへ所属させることはできない。
- 作成条件を満たさない場合はパーツを追加せず、既存の作図内容と履歴を維持する。
- パーツは作成が成功した時点で固定され、回転、拡大縮小、個別図形の編集、構成要素や外形・穴の変更を受け付けない。

### 14.2 構成要素と固定

- パーツは外形、穴、通常図形、オフセット線やフィレット、自由テキスト、計測表示を構成要素として管理できる。丸穴、折り線、縫い線、縫い始め点は、それぞれの参照図形または派生要素を通じてパーツ内で扱える。
- パーツ作成時に、選択図形へ依存する既存の派生要素と計測表示、および外形内の既存自由テキストはそのパーツへ所属する。
- パーツ作成後に外形内へ追加した図形、派生要素、自由テキスト、計測表示は、既存パーツへ自動所属せず独立した作図内容として保持される。
- パーツの通常図形、派生要素、自由テキスト、計測表示、拘束、参照パラメータの変更、および構成要素の追加・除外と外形再設定は拒否される。拒否時はドキュメントと履歴を変更しない。
- パーツを解除しても、所属していた図形と付随要素は削除されない。
- パーツの構成要素を編集または削除するには、先にパーツを解除する必要がある。

### 14.3 パーツ単位の選択、位置変更、複製

- パーツを選択すると、所属する通常図形と解決済み派生図形、自由テキスト、計測表示、縫い始め点がキャンバス上で強調表示され、パーツ原点が十字マーカーで表示される。
- 選択したパーツは、キャンバスのドラッグまたは10 mm単位の移動ボタンでまとまりとして移動できる。通常図形、自由テキスト、原点が同じ差分で移動し、参照に基づく派生要素、丸穴、縫い始め点、計測表示、寸法表示は位置関係を維持する。
- パーツを複製すると、元パーツを残して名称、配置基準点、固定された外形、穴、所属要素、内部拘束、注釈を持つ別IDの固定パーツを作成する。共有パラメータと共有スタイルの参照は維持する。
- 位置のX/Y座標を数値入力できるほか、「キャンバスで位置を指定」の次のクリック位置へパーツ全体を移動できる。位置指定待ちは再押下またはEscで取り消せる。
- パーツ移動、複製、整列、等間隔配置は、それぞれ1回のUndo/Redo単位として扱う。

### 14.4 保存、出力、パーツ間寸法連動

- 複数パーツと各パーツの名称、原点、外形、穴、構成要素の所属関係は `.lcraft` に保存され、読み込み後に復元される。
- 出力対象となる全パーツの図形と付随要素は、従来の表示・印刷対象ルールに従って同じ出力へ含まれる。
- パーツ化前の複数図形の寸法拘束または派生要素から同じ名前付きパラメータを参照することで、作成時の寸法を一致させられる。パーツ化後に共有パラメータを変更して形状を更新することはできない。
- 二つ折り財布の型紙を、札入れ、カードポケット、小銭入れ、マチなどの複数パーツとして作成、保存、出力できる。

### 14.5 表示、印刷、固定、必要数量

- パーツごとに編集キャンバスへの表示と、PDF・直接印刷への出力を独立して切り替えられる。切り替えは所属要素だけに作用し、未所属要素や別パーツへ影響しない。
- すべてのパーツは固定される。名称、位置、表示、印刷対象、必要数量は変更できるが、固定解除はできない。
- 必要数量は1以上の整数で管理し、保存・読み込み、複製、ライブラリ配置で維持する。必要数量によってキャンバスまたは出力の形状を自動複製しない。

### 14.6 整列、等間隔配置、パーツライブラリ

- 2個以上のパーツを外形の左端、左右中心、右端、下端、上下中心、上端で整列できる。
- 3個以上のパーツを外形間の左右または上下の空きが等しくなるよう配置できる。整列と等間隔配置はそれぞれ1回のUndo/Redo単位である。
- パーツを端末内のローカルライブラリへ登録し、別プロジェクトへ独立したIDのパーツとして配置できる。所属要素、必要数量、参照する共有スタイル、レイヤー、名前付きパラメータを再利用する。配置先に同じIDで異なる依存情報がある場合は、誤った置換をせず配置を拒否する。

## 15. 履歴

- 成功した編集操作は Undo できる。
- Undo した操作は Redo できる。
- Undo 後に新しい編集操作を行うと、Redo 履歴は破棄される。
- 空履歴での Undo/Redo は拒否され、ドキュメント状態を変更しない。
- 線分作図と、それに伴う自動付与拘束は1つの履歴単位として扱う。
- 複数エンティティの移動、複製、削除、計測表示から拘束への変換など、利用者にとって1操作であるものは1つの履歴単位として扱う。
- Undo/Redo は、進行中の一時入力、ドラッグプレビュー、作図ドラフト、拘束対象選択を消したうえで状態を戻す。

## 16. 出力と印刷

### 16.1 出力対象

- 現在のドキュメント全体を、A4固定・100%実寸でPDF出力または直接印刷できる。
- 出力対象がA4一枚に収まらない場合は、A4単位の複数ページとしてPDF出力または直接印刷できる。
- 自動縮小、自動拡大は行わない。
- 出力シートを開いた時点では、用紙向きはキャンバスのA4基準表示の向きを初期値として取り込む。
- 出力シートを開いている間は、用紙向き、回転、寸法数値表示、50mmスケールガイドの選択は、出力シート上の設定を正として扱う。
- 出力シートで用紙向きを変更すると、キャンバスのA4基準表示も同じ向きへ更新する。
- 回転は `0°` または `90°` から選択できる。
- PDF出力と直接印刷は同じ配置結果を使う。

### 16.2 出力に含まれるもの

- 表示レイヤー上にある点、線分、円、円弧、中心線を出力できる。
- オフセット線は、解決済み図形として出力される。
- フィレットは、トリム済み線分と円弧として出力される。
- 自由テキストは、配置済み注記として出力される。
- 縫い始め点は、点 marker として出力される。
- 寸法拘束の数値表示は、出力設定で含めるか切り替えられる。
- 50mmスケールガイドは、出力設定で含めるか切り替えられる。
- 複数ページ出力では、ページ番号、隣接方向、ページ境界の基準線を貼り合わせガイドとして含める。
- 中心線は出力対象に含める。

### 16.3 出力に含まれないもの

- 非表示レイヤーまたは印刷対象外レイヤーの要素は出力に含めない。
- グリッド、A4基準表示、拘束マーク、選択ハイライト、作図中プレビューは出力に含めない。
- 計測表示は現行の PDF 出力と直接印刷には含めない。

### 16.4 警告と失敗

- 空ドキュメント、または出力対象が存在しないドキュメントは警告対象であり、出力を完了しない。
- 印刷可能領域からはみ出す場合は警告し、利用者は続行または中止を選べる。
- 実寸が最終的に保証できない可能性がある場合は警告対象になる。
- 出力シートでは、総ページ数、警告件数、警告内容、全ページの縮小プレビューを出力実行前に確認できる。
- 出力対象がない場合、PDF出力設定を開いた時点で総ページ数を `0` と表示し、出力対象がない警告を表示する。
- 警告がある場合、利用者が同じシート上で警告確認を明示するまで、保存または印刷は実行できない。
- 直前に出力シートへ表示された ready 状態の配置結果を、そのまま PDF 生成または直接印刷へ渡す。
- 出力ページが生成できない、不正な用紙サイズ、不正な回転角、PDF/印刷データ生成失敗は失敗として扱い、保存または印刷を開始しない。
- 出力対象がA4 5x5範囲の外に出る場合は失敗として扱い、保存または印刷を開始しない。
- 直接印刷では、macOS 標準の印刷設定でプリンタ、A4、倍率、印刷可能領域を確定した後、その設定から再構築した配置結果を最終確認シートへ表示する。
- 直接印刷の最終印刷には、最終確認シートのプレビュー生成に使った同じ印刷設定を使う。


## 17. 対象外

- 菱目などの未実装レザークラフト固有要素の詳細仕様
- 素材歩留まりを考慮する自動ネスティング配置
- パーツ外形への直接寸法参照、パーツ同士を直接参照する拘束
- 製品テンプレート自動生成
- A4以外の用紙サイズ、重なり代付き出力、手動ページ配置
- SVG、DXF、CAM、プロッター、レーザー加工出力
- 未実装機能の予定仕様
