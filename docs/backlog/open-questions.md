# 未確定要件・詳細化事項

## 1. 文書の目的

本書は、現行基盤を継続的に拡張する中で、実装前に判断が必要な事項を管理する。確定済み要件と外部仕様は `docs/spec/functional-spec.md` と `docs/spec/ui-ux-spec.md` を正とする。

## 2. 詳細化事項

| 優先度 | 状態 | 項目 | 判断する内容 |
| --- | --- | --- | --- |
| P1 | 未決定 | 名前付きパラメータ一覧 | 並び替え、検索、使用件数による絞り込みの範囲 |
| P1 | 未決定 | 拘束状態の視覚表現 | 拘束不足、完全拘束、冗長拘束、競合の色、アイコン、集約表示の文言 |
| P1 | 未決定 | 拘束不足時の補助表示 | 残っている自由度の方向や対象をどこまで可視化するか |
| P2 | 未決定 | 印刷時の注意表示文言 | PDFおよびアプリ内印刷画面に表示する、実寸印刷確認の具体文言 |
| P2 | 未決定 | 出力設定の永続化範囲 | 用紙向き、寸法表示切り替え、50mmガイド表示、回転選択を、プロジェクト設定として保存するか、直近操作として扱うか |
| P2 | 未決定 | 性能基準と代表データ規模 | 想定する図形・拘束・パーツ数と、作図操作、保存、読み込み、出力で許容する応答時間をどの代表型紙で計測するか |
| P3 | 未決定 | 型紙要素のデフォルト値 | 縫い線オフセット、丸穴径、縫い始め点表示などの初期値 |
| P3 | 未決定 | 未使用パラメータのアクセシビリティ表現 | 説明アイコンを読み上げ対象外にするか、未使用状態と分かるラベルを付けるか |
| P2 | 未決定 | レイヤー操作のアクセシビリティ | レイヤーの表示・印刷・削除操作を、実行結果と一致する日本語の名前と状態として読み上げる方法 |
| P3 | 未決定 | 新規ドキュメントの日本語表記 | 新規ドキュメントだけに残る既定レイヤー名・操作名の英語表記を統一する範囲 |

## 3. 昇格ルール

詳細化事項を実装対象にする場合は、`docs/README.md` に従って issue 化し、必要な要件、設計、境界仕様へ反映する。判断が確定した項目は本表から削除し、決定内容を対応する正本文書へ移す。
