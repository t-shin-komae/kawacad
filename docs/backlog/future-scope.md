# 将来の拡張候補

## 1. 文書の目的

本書は、現行基盤に対する将来の拡張候補を管理する。現在の実装対象ではなく、利用者価値と優先度を検討するための材料として扱う。

## 2. 利用形態・プラットフォーム

- Windows対応、クロスプラットフォーム対応
- オンライン機能、クラウド同期、アカウント連携

## 3. 作図・パラメトリック機能

- パラメータ計算式、条件分岐
- ベジェ曲線、自由曲線
- 既存図形からの中心線生成
- 図形要素単位の対称拘束
- ミラー作図コマンド
- 選択範囲からの中心線自動生成
- 円穴を矩形の中心線へ対称配置する補助導線
- 左右/上下辺からの等距離拘束
- 補助線として作成した中心線への点-線一致拘束
- 拘束不足時に残っている自由度の方向や対象を示す表示

## 4. 型紙・レザークラフト機能

- 通常スリット
- 財布以外の革製品への対応
- 複数サイズ展開
- 革厚補正
- スタイルのアプリ全体テンプレート化
- 曲線に沿った縫い穴配置
- 菱目配置モードの詳細仕様
- 縫い穴や菱目開始位置の詳細表示
- 素材サイズ、回転可否、革目を考慮するパーツ自動ネスティング
- パーツ外形の幅・高さを直接参照する拘束
- パーツ間の直接参照関係をキャンバス上の非印刷線で可視化する表示
- 高度なパーツ間対応関係管理
- 縫い合わせ範囲の長さ一致
- 穴列・菱目列の開始位置、終了位置、数の対応
- 丸穴用途別プリセット、金具規格チェック
- 型紙販売向けの注記・説明出力

## 5. 出力・加工連携

- A4以外の用紙対応
- 重なり代付きの貼り合わせ出力
- 手動ページ配置、利用者指定のページ範囲
- ミシン、レーザー加工、プロッター出力対応
- SVG出力、DXF出力

## 6. 昇格ルール

拡張候補を実装対象へ昇格する場合は、`docs/README.md` に従って issue 化し、対象範囲と対象外を確定してから要件と必要な設計文書へ移す。
